# 北极星 · Northstar English

面向中文母语儿童的英语听说练习项目。这个首次公开版本提供从现有北极星项目提取的学习引擎、可运行的原创示例，以及可选的语音评分适配器。

**状态：早期公开预览（0.1.0）。** 当前公开演示使用浏览器朗读和原创词句，不包含家庭版动画、教材、预制声音、私人配置或真实学习记录。没有规模化用户数、下载量或学习效果的公开验证。

## 运行

需要 Node.js 20 或以上版本。没有 npm 运行依赖，无需 API Key。

```sh
npm start
```

打开终端显示的地址，默认是 **http://127.0.0.1:18731**。使用 HTTP 服务打开，不能直接双击 HTML。修改端口可用 `PORT=18732 npm start`；服务器仅监听本机。

## 可以体验什么

- 10 个原创示例词的单词/例句朗读，主动选择正常或慢速。
- 意义选择、词义配对、听音选择，保留第一次错误的证据。
- 中断后刷新续练；记录缺失显示为未知。
- 每日奖励仅结算一次；重复打开总结不会重复发奖。
- 两课原创语境按课续练，同词在不同课保留各自的例句。
- “稍后再练”单列保存，不生成虚假的发音分或掌握记录。

演示中的朗读使用设备/浏览器的 Speech Synthesis，音色和可用性因设备而异；相关服务可能由操作系统或浏览器提供，不保证完全离线。此公开演示不访问麦克风，也不发出语音评分请求。听音题只有朗读正常结束后才接受答案；没有声音时可以退出并稍后继续，不冒充完成。

## 目录

| 路径 | 用途 |
| --- | --- |
| `core/storage.js` | IndexedDB 存储及串行写入 |
| `core/review-engine.js` | 单词规范化、间隔复习与进度更新 |
| `core/animation-curriculum.js` | 按语境分课和续练；可用于原创课程 |
| `core/speaking-progress.js` | 逐词/整句证据、低分退出、语境隔离 |

| `core/rewards.js` | 学习日、结算与奖励去重 |
| `adapters/tencent-soe.js` | 可选腾讯智聆采集/解析适配器 |
| `demo/` | 独立公开预览与原创示例 |
| `tests/` | 合成数据回归测试 |
| `docs/source-provenance.json` | 原项目到公开文件的相对路径、哈希与修改说明 |

这些引擎文件来自已有北极星工程，不是空仓库或申请占位。引擎保留现有浏览器全局脚本接口，尚未整理成通用 npm 模块。公开演示采用一个小型新界面接入它们，**并非完整家庭版产品的镜像**。

## 存储与内容

预览使用独立数据库 `northstar_english_public_preview_v1`，不会读取原应用数据库。不要向公开 issue 上传孩子的录音、学习记录、邀请链接或 API 凭据。

仓库只含程序、原创示例及合成测试数据。第三方动画、字幕、教材、词库、音素和声音包不在本次发行中。MIT 许可证只覆盖本仓库实际提供的内容。

## 可选语音评分适配器

`adapters/tencent-soe.js` 保存了原项目的录音、PCM 转换和腾讯返回值解析实现，**演示不加载它**。它不是可以直接调用的完整评分服务。

接入需要你自己的同源 `GET /api/tencent-soe-url` 签名服务、腾讯账号配置、HTTPS 或 localhost 环境及用户主动同意。参数为 `ref_text`、`eval_mode` 和 `rec_mode`；成功响应需包含 `url`（签名 WebSocket URL）及 `debug.rec_mode`。密钥只放服务器环境变量。适配器的 `assess()` 会获取麦克风并将音频直接传至腾讯；使用前应在你的产品中清楚告知、获得许可并设置额度。原始适配器仍是实验实现，未在公开版做真实麦克风、iPad或第三方付费服务验收。

默认服务器没有签名端点，也不代理第三方词典服务。
